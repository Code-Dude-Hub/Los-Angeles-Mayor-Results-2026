Where the numbers come from

The data is retrieved by GitHub Actions from LA County's official election JSON file. Refresh reads the latest published snapshot on this site. A new county report can appear only after GitHub Actions successfully checks and republishes it. No PC server and no website-side access token are needed.

The published numbers are preliminary. "Leading" means ahead in counted votes, not a declared election winner. The estimated vote-counted percentage is separate from official votes: it uses ABC7’s previously published 51% expected-vote estimate when 602,896 mayoral votes were counted. The baseline may change, and this estimate should not be treated as an exact live percentage. On an upstream fetch error the last verified report stays published.
